# Code of conduct

Be direct about the code and generous about the person.

- Critique a patch, a rule, or a false positive with the evidence: the unit
  file, the line, the output. "This is wrong" without a reproducer is not a
  contribution.
- No harassment, no personal attacks, no gatekeeping about which systems
  someone administers or which distribution they run.
- Security research is welcome here, including research that demonstrates how
  a finding in this tool's output is exploited. Keep it to systems you own or
  are authorised to test.
- Maintainers may close issues that are only a demand for free support. That is
  not a judgement about the person.

Reports about behaviour go to the address in `SECURITY.md`.
